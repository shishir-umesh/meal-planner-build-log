# 2026-10-03: Sprint 1

Reviewed early: every coding task for the sprint (Sep 28 – Oct 11) had merged by Oct 3.

## Shipped
- **App scaffold.** Expo (TypeScript, Expo Router) for iPhone and the web, with strict TypeScript, ESLint and Prettier, and the `src/core` / `src/data` / `src/ui` split from day one.
- **Tests and CI.** Jest and React Native Testing Library, with an 80% coverage floor on `src/core`. The first real logic, days-until-expiry, was written test-first, including the daylight-saving edge cases. CI runs typecheck, lint, formatting, tests with coverage and a secret scan on every pull request; a deliberately failing test proved it goes red.
- **Development builds on both iPhones.** Decision 6: iOS and web only, and the Apple Developer Program joined now so the app on my wife's phone doesn't stop opening every 7 days. Both phones run the development build and pick up code changes live.
- **End-to-end smoke test.** A Maestro flow launches the app on the simulator and checks the home screen, even when the development build opens on its launcher or dev menu first. It runs locally only; CI on macOS costs about 10 times as much as Linux.
- **Storage and sync decided** (decision 7, after a 4-hour spike). Household data lives in Firestore on the free plan: the native Firebase SDK on the iPhone and the Firebase JS SDK on the web, behind one repository interface.
  - Changes reached the other device in well under a second. Round trips were about 0.3–0.6 s on a real phone over Wi-Fi.
  - Items added in Airplane mode, while the app was killed, or before a browser reload all synced once the device came back.

## Learned
- **Prototype before trusting the docs.** React Native Firebase says it "falls back to the Firebase JS SDK" on the web. In practice that fallback is Firestore Lite, with no live updates and no offline cache. The spike caught it in minutes; reading alone hadn't.
- **The free plan is about reads, not writes.** Writes for a two-person household are tiny, about 100 a day. Reads come mostly from re-reading lists when an app reopens. The iPhone's offline cache cut a reopen from a full re-read to 2 reads, which is why the native SDK won over the simpler JS-only option.
- **Apple setup is most of a "4-hour" device task.**
  - Accept the Xcode license after every update.
  - A new signing certificate stayed invalid until a missing Apple intermediate certificate was installed.
  - `codesign` waited silently on a hidden keychain dialog.
  - The second phone had to be registered before it could install the app.
  None of this was hard, but each step stopped the build until someone noticed. They're all written down now.
- **Security review on a throwaway prototype still pays off.** It listed exactly what the real household setup needs: single-use invite links, a way to remove members, App Check, private data per person, and accounts that survive a reinstall.
- **Write the gotchas down where the next session reads them.** Each surprise this sprint became one line in the project's instructions for Claude, so it gets hit once, not every sprint.
